Sistema de ventas — dirección visual

Cuatro estilos, un mismo sistema

Misma pantalla de referencia (barra superior, indicadores, una fila de comprobante, botones) resuelta con cuatro paletas y tipografías distintas. Cada una está pensada para un tipo de negocio distinto — no es solo un cambio de color, cambia el carácter completo.

Responde con el nombre del estilo que prefieras (o combina piezas de varios) y lo aplico a todo el sistema — Punto de Venta, Productos y Comprobantes.
